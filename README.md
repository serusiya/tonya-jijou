# 《問屋事情》——關於我成了日之國中盤商這件事

**《問屋事情》** 是一款以日式古地圖與虛構江戶時代為背景的網頁版經商模擬遊戲。玩家將扮演「日之國」百城之中的一名問屋（中盤商），在詭譎多變的市場行情、爾虞我詐的同業公會，以及貪腐交織的奉行所之間，建立自己的商業帝國。

遊戲強調真實的「盤商」體驗：你不是四處漂泊的行商，而是坐鎮本城、掌控物資吞吐的樞紐。透過純前端技術（HTML5 Canvas、JavaScript、Web Audio API）打造，遊戲內建了隨機生成的千人名冊與專屬的日本傳統器樂配樂（如《市井囃子》、《道中囃子》），無需後端伺服器即可在瀏覽器中流暢運行。

##  核心遊戲特色

###  動態相場與大盤博弈

* **擬真供需系統**：商品收市價會根據「近九旬的總出貨量與需求」動態計算，分為必需品、一般品與奢侈品，各有不同的價格彈性與發酵視窗。


* **事件與天災**：物價會受季節、節慶、大名行列過境，以及「春疫病、夏颱風、秋凶作、冬大火」與軍需事件的強烈衝擊。


* **產地與外運**：除了向大盤進貨，玩家還能派遣船長與飛腳前往產地「委託採買」，甚至利用「外運販售」與「卸留請負」將本城消化不完的貨物運往外城傾銷。


* **大盤制裁與豪商**：當玩家市佔率高達 25% 且不受大盤控制時，大盤問屋將發動商戰制裁（下游壓價、大口買付斷貨、勒令停業，甚至補貼同業兩倍出貨砸盤）。撐過制裁即可獲得「豪商」名號，並觸發大盤五萬兩收購商株的強迫搬家事件。



###  問屋公會與暗盤交易

* **公會例會**：每季（3、6、9、12 月上旬）召開例會。會員需表態是否繳交訂約金加入「聯合採購與出貨協議」，享受進貨折扣但受配額限制。


* **供給投票與拍賣**：在例會上與同業投票決定本期方針（維持／減供），並可出價競標大盤孝敬官府的賄賂品「菓子折」。


* **公會長選舉**：每年 3 月改選公會長，玩家可透過「拜訪戰鬥」向同業塞錢拉票；當選後除了握有平手裁決權，還需親自向御金奉行報告並上繳得標金，甚至能仲裁同業糾紛或攤派御用金。



###  官場鑽營與特權許可

* **三系官署與遠國奉行**：與普請方（行政）、勘定方（財務）、吟味方（司法）及各地區遠國奉行所打交道。高階官員（五、六階）會於特定月份巡迴來城。


* **拜訪戰鬥（攻心之戰）**：拜訪官員不再只是無腦砸錢。玩家必須根據官員的性格（貪官、清官）、軟肋送對禮物，並在三個回合中猜測對方的「期待價碼」出價。打穿心防才能提出請託，若被嫌「不善言辭」將被拒見。


* **擴張特權**：取得擴建倉庫、增加船長與保鏢的許可。高階請託甚至能實施「專賣株」、「新町取立」、詐領官銀的「破船賑／盜難賑」、向大名放款的「大名貸」，或勒令同業停業的「株札暫扣」。



###  爾虞我詐的極道手段

* **暗黑流派**：雇用保鏢暗殺對手、放火燒倉，或委託私梟脫手違禁品與走私黑貨。


* **天理昭彰的木戶黃門**：風聲過高會引來欽差突查罰款。而進行暗殺、放火、栽贓、闕所等惡行會累積隱藏的「惡德值」；當惡德值過高時，微服出巡的木戶黃門將亮出印籠替天行道，將玩家打回白手起家的狀態。



###  夥計管理與後宅人生

* **自家栽培**：店員擁有商才、忠誠、膽識等數值，每年會自然成長；提拔自家栽培的夥計可大幅降低其私吞與捲款潛逃的風險。


* **查帳與暖簾分**：根據風聲對店員查帳，可選擇寬恕、追討或辭退。當大番頭貢獻良多且現金充裕時，可資助其前往隔壁城開分號（暖簾分），日後分號將定期送錢回報。


* **壓力與出遊**：頻繁交涉或遇上壞事會累積壓力，進入「疲憊」狀態將導致交涉按鈕亂序、進出貨拉霸手抖；過勞更會直接病倒。可透過宴會、吉原夜宴，或前往寺社參拜、泡溫泉減壓，旅途中還會遇上三助詐騙、賣藥郎、三獻茶等豐富的市井奇遇。


* **人生終章**：遊戲沒有世代傳承，僅有這一生。結局由壽終、破產、處刑或主動退隱決定，落幕時將獲得蓋棺評語，隨後即可重開新局。


## 開發方式

本遊戲由**人類設計、AI 輔助實作**：玩法、規則、數值與流程由設計者逐項指定與調整，程式碼主要由 Claude（Anthropic）協助撰寫。

### 自行建置

```bash
cd build
python3 -I build.py        # 產生單一 HTML 檔
```

`build/js/` 下的檔案依檔名排序後串接；費用、機率、台詞、按鈕文字、訊息與旬報文字分別集中在 `01b_costs.js`、`01c_odds.js`、`01d_lines.js`、`01e_ui_text.js`、`01f_messages.js`、`01g_news.js`，要改數值或文案，優先改這些表。

### 隱私與安全

遊戲完全在你的瀏覽器裡執行，不收集任何資料，也不連線到任何伺服器（僅載入 Google Fonts 的字型）。存檔放在瀏覽器的 localStorage，清除網站資料就會消失。
