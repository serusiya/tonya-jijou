# 問屋事情
### 關於我成了日之國中盤商這件事

「拜訪是一場攻略人心的戰鬥」

一款在瀏覽器裡就能玩的**像素風江戶商人人生模擬**。單一 HTML 檔案，不用安裝、不用註冊、不用連線，手機與電腦都能玩，存檔留在你自己的瀏覽器裡。

> 20 歲開局。沒有固定的目標，只有一生。

---

## 遊戲說明

你是一名剛開業的**問屋**（批發中盤商）。上承產地，下接市井，夾在奉行所、同業公會和花街之間。每一旬（十天）你有 5 點行動力，要用它進貨、出貨、拜訪人物、打通關係、經營商號。沒有固定的過關條件，也沒有分數，遊戲結束時只有一篇「蓋棺評語」總結你這一生。

### 開局選擇

| 行業 | 風格 | 特色 |
|---|---|---|
| 材木問屋 | 豪賭型 | 木材易燃，一場大火可翻十倍，也可能燒光倉庫 |
| 米問屋 | 政治壓力型 | 薄利多銷；主食漲價會引發打毀，靠山弱就當替罪羊 |
| 魚鹽問屋 | 高損耗快周轉 | 鮮魚每旬損耗兩成，必須快進快出 |
| 金物鐵石問屋 | 金融軍工型 | 銅鐵金銀關乎幣制與軍需，官府人脈是關鍵 |
| 木棉生絲問屋 | 大宗調度型 | 量大、跨城調度，船隊與商路最吃重 |
| 唐物藥種問屋 | 走私型 | 南洋香辛利潤驚人，免檢通關與緝私官員是命脈 |
| 陶磁雅玩問屋 | 公關型 | 賣的是品味與人情；開局資源最豐厚 |

### 你可以做的事

- **買賣與市況**：向大盤進貨、分旬出貨；價格隨季節、供需、市佔率、突發事件（火災、凶作、颱風、疫病……）波動。
- **商路**：開海運與陸運，從產地運貨；船長與飛腳的膽識影響風險。
- **人脈**：登門拜訪、送禮、請託；好感決定對方辦不辦事。許可與權利要走**申請流程**（6 旬、最短 3 旬、最長 12 旬），還要繳規費，貪官與清官的收法不同。
- **官府**：行政、財務、司法官員各有專屬門路。好感滿 100 後，司法官員可為你「栽贓」同業，行政官員可「打壓」同業，財務官員會開口要你「上貢」。
- **雇員**：丁稚、手代、番頭、大番頭，加上船長、飛腳、保鏢。給零用錢養好感；好感滿 100 後，保鏢可「暗殺」、膽識夠的手代與番頭可「放火」、船長肯跑「走私」。
- **吉原**：八名伶人，每旬四人在席；指名、送禮、包場夜宴，好感滿了可以贖身納為側室。花得太兇商譽會受損。
- **走私與搜查**：走私利潤高，但官府搜查、遠島判決就在前面。
- **同業公會**：株仲間定配額，守約還是偷跑是一道囚徒困境。
- **家族與傳承**：成家、生子、培養繼承人。你會老、會死，家業由下一代接手，人脈與舊怨一併承襲。

遊戲世界裡每個人有自己的性格、弱點與好惡。

### 操作

手機優先：點畫面上的場所與按鈕即可。底部四個分頁（市場、商路、筆記、私宅），右下角「推進一旬」。桌機也能用滑鼠操作，`Esc` 關閉面板。

## 與《天下御免》的關係

本作的靈感來源是《天下御免》——**沒有固定目標、只有一生的商人人生模擬**，這個精神也貫穿本作：不追求通關，而是在利益、人情、風險與道德灰色地帶之間，走完一個商人的一生。

**本作沒有引用任何《天下御免》的素材。** 程式碼、文字、數值、人物與圖像都是重新製作，僅在設計理念上延續。「問屋事情」是獨立的作品。

## 開發方式

本遊戲由**人類設計、AI 輔助實作**：玩法、規則、數值與流程由設計者逐項指定與調整，程式碼主要由 Claude（Anthropic）協助撰寫。

### 自行建置

```bash
cd build
python3 -I build.py        # 產生單一 HTML 檔
```

`build/js/` 下的檔案依檔名排序後串接；費用、機率、台詞、按鈕文字、訊息與旬報文字分別集中在 `01b_costs.js`、`01c_odds.js`、`01d_lines.js`、`01e_ui_text.js`、`01f_messages.js`、`01g_news.js`，要改數值或文案，優先改這些表。

### 隱私與安全

遊戲完全在你的瀏覽器裡執行，不收集任何資料，也不連線到任何伺服器（僅載入 Google Fonts 的字型）。存檔放在瀏覽器的 localStorage，清除網站資料就會消失。
